## 0. Variants, definitions, validation
Unit value u(t) = USD value of one unit of account. Debt is fixed in units, so debt value in USD = D x u(t); in the simulator u(t) is the index I(t) that multiplies debt value everywhere (ICR, auctions, redemption, ledger, latent hole). A vault opened at 200%: ICR(t) = 200% x (KAS_usd(t)/KAS_usd(0)) / (u(t)/u(0)). "Up" = unit revalues against USD (raises debt value in USD: adverse for the system); "down" = unit loses USD value (adverse for ENRK holders measured in USD).

## 1b. RUB data handling (U3b)
Source: CBR official rate (an administrative daily rate set by the Bank of Russia, not a tick market rate; XML keyless). Gaps: weekends/holidays carry the rate set in advance, so the series has no missing days (max 13-day gap between records early in the file). Official vs market quote (Yahoo RUB=X, unofficial, contains bad ticks, e.g. 5.0 on 2023-03-16): 2014-12-10..24: median -0.09%, p95 |dev| 10.6%, max 10.9% on 2014-12-16 (CBR 58.3 vs market 65.5); 2022-02-22..04-15: median -1.58%, p95 |dev| 13.6%, max 16.3% on 2022-03-10 (CBR 116.1 vs market 138.7); 2023-2026 calm: median -0.03%, p95 |dev| 1.7% (outliers excluded by using the median). The official rate was therefore up to 11-16% below the quoted market rate on stress days; the official series is what the history and simulation use (U3b), and a market-rate version would show larger 2022 moves than reported here. 2022 closure: the Moscow Exchange stock market was shut by decision of the authorities in late Feb-March 2022 (Wikipedia "Russian ruble", secondary) while the CBR kept publishing official rates every day (see the file: 2022-03-01 93.6, 03-04 111.8, 03-10 116.1, 03-11 120.4, 03-25 96.0). Largest 1-record moves of the official rate: +12.5% (2022-03-03), -12.1% (2014-12-19), +12.0% (2022-03-01), +11.6% (2015-01-13). ECB: reference rate for EUR/RUB last published 2022-03-01 and suspended "until further notice" (ECB page text; the eurofxref file ends there too: 4333 RUB observations 2005-04-01..2022-03-01).
Effect of adding RUB to the basket: vol 2.9% (USD/EUR/CNY) -> 4.5% (USD/CNY/RUB equal) or 2.7% (50/30/20); worst 60-day UP 5.2% -> 24.8% / 14.3%; worst DOWN -5.1% -> -13.6% / -8.3%; 365d return p5/p95 -2/+6% -> -6/+10% (eq). ICR history: touch 63 -> 62 / 62%, ICR<100% 28 -> 29 / 29%; ICR minima for the vaults tabulated above moved by +-4 points. Crash simulation: see section 2 (typical windows no effect; worst-window replay raises A3 unbacked 10.2 -> 14.9 (eq) / 13.0 (50/30/20) vs 11.6 for the USD/EUR/CNY basket).
